# さくらWEBメール HTML表示（非公式）

さくらのレンタルサーバ／さくらのメールボックスの **WEBメール** で、HTMLメールを見た目どおりに表示できるようにする Chrome 拡張機能です。いつものWEBメールを、もっと便利に使いたい方へ。

| 導入前 | 導入後 |
| --- | --- |
| HTMLメールは、`<!DOCTYPE html>` から始まるソース（文字）で表示されます | HTMLメールが、送り手のデザインどおりに表示されます |

> **これはさくらインターネット株式会社とは関係のない、非公式の拡張機能です。**
> 本拡張機能についての、さくらインターネットへのお問い合わせはご遠慮ください。

## できること

- WEBメールでHTMLメールを開くと、自動でHTMLとして描画します
- プレビューが途中で切れている（「続きがあります…」）場合は、「続き」ボタンを自動で押して全文を読み込んでから描画します
- 本文の上の「ソース表示に切り替え」ボタンで、いつでも元のソース表示に戻せます
- メール内のリンクは新しいタブで開きます

## 安全性について

- メール内のスクリプト（JavaScript）は **一切実行されません**（スクリプトを禁止した iframe の中で描画しています）
- 拡張機能が動くのは `https://secure.sakura.ad.jp/rscontrol/` の中だけです
- メールの内容をどこかに送信することはありません。通信も一切行いません
- ただし、メール内の **画像は外部から読み込まれます**。一般的なメールソフトと同様、送信者に「メールを開いた」ことが伝わる場合があります

## インストール方法

Chromeウェブストアには公開していないため、次の手順で読み込みます（Edge など Chromium 系ブラウザでも同様です）。

1. このページ上部の緑色の **「Code」** ボタン → **「Download ZIP」** でダウンロードし、解凍します
2. Chromeのアドレスバーに `chrome://extensions` と入力して開きます
3. 右上の **「デベロッパーモード」** をオンにします
4. **「パッケージ化されていない拡張機能を読み込む」** をクリックし、解凍したフォルダの中の **`extension`** フォルダを選びます
5. さくらのWEBメールを開き直して、HTMLメールを表示してみてください

> 解凍したフォルダは削除・移動しないでください。拡張機能はそのフォルダから動いています。

### 更新するとき

新しいバージョンをダウンロードして `extension` フォルダの中身を上書きし、`chrome://extensions` で拡張機能の再読み込みボタン（丸い矢印）を押してください。

## うまく動かないとき

さくらのWEBメールがアップデートされて画面の作りが変わると、この拡張機能の追従が必要になることがあります。[不具合の報告](../../issues/new/choose) から、テンプレートに沿って報告してください。テンプレートに載っている **診断用コード** の結果を添えてもらえると、原因の特定が早くなります。
